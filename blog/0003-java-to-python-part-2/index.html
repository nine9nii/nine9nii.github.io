TreeMap and TreeSet → sortedcontainers

Python's standard library has no balanced BST. This is the biggest gap coming from Java.

One option is the third-party sortedcontainers package. Check whether your interview environment provides it; if not, a sorted list plus bisect can work when linear-time insertion is acceptable (see below).

TreeSet → SortedSet (or SortedList for duplicates)

SortedSet is the closer match when values must be unique. SortedList keeps duplicates, making it useful for multiset problems. The example below uses SortedList to show floor and ceiling operations.

One difference: SortedList allows duplicates, like a multiset. That's often exactly what you want for a sliding window median. Use from sortedcontainers import SortedSet and SortedSet() when you need unique values.

Bonus that Java's TreeSet doesn't have: indexing is approximately O(log n), so sl[k] gives you the k-th smallest element directly.

TreeMap → SortedDict

No library? bisect on a sorted list

The bisect module (standard library) gives you binary search on any sorted list:

Lookups are O(log n), but insort is O(n) because inserting shifts elements. Fine for most interview sizes; a real TreeMap replacement only matters when you have lots of interleaved inserts and queries.

bisect_left is also your Collections.binarySearch — and it's much less error-prone than writing binary search by hand.

Recursion

Recursion translates directly. Two things are different, and both matter.

Memoization is one decorator

The real fix: manage the stack yourself

The robust approach is the one that works in any language: replace the call stack with an explicit stack. Recursion is just the language keeping a stack of "what was I doing" for you — you can keep it yourself.

My rule of thumb for interviews: write the recursive version first because it's clearer, mention the depth limit out loud, and convert to an explicit stack if the input can be deep (linked lists, skewed trees, grids up to 10⁶ cells).

Cheat sheet

The pattern across both parts: Python usually has a shorter way to say the same thing, and the places where the mapping breaks — integer division, the shared-row 2D list, missing TreeMap, the recursion limit — are exactly the ones worth memorizing before the interview.
