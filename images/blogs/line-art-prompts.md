# Blog cover prompts

Created with the built-in image generation tool. Covers are saved alongside this file as `*-line-art.png`.

## distrobox

Use case: stylized-concept. Asset type: technical blog cover. Create one original minimalist editorial line-art image about nested open wireframe boxes connected through one shared base, suggesting Linux containers integrated with their host. Very wide landscape composition approximately 2.4:1. Pure white background, fine crisp black strokes only, airy and restrained, ample negative space, geometric and slightly playful, like a mathematical pen plotter drawing. Keep drawing within central 70% of canvas. No text, no letters, no numbers, no logos, no gradients, no shadows, no colors, no solid filled shapes, no border. This is one of a consistent series for a personal engineering blog.
